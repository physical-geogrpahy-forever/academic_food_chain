## Ability QA2 notes

- Astronomy specialists no longer mostly repeat `Observatory +1/+2 Science`.
- Tycho and Galileo use multi-charge active abilities.
- Kepler uses science-trade coupling.
- Cassini uses empire Observatory count for a one-time burst.
- Rømer uses maintenance efficiency.
- Harriot uses Navigation rather than another Observatory modifier.
