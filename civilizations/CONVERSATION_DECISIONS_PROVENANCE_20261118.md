## 출처 판정 방법

- `U-DIRECT`: 이전 대화에서 **사용자가 직접** 요청·수정한 사실로 검색 확인.
- `A-DRAFT`: 이전 대화에서 **어시스턴트가 제시**한 초안. 사용자 최종 합의와 동일시 금지.
- `GH-HANDOFF`: GitHub 원문에 기록된 내용. 과거 대화의 2차 요약이며 확정 권위와 동일시 금지.
- `GH-AUTHORITY`: 실제 잠금 선언이 있는 GitHub 설계 파일의 해당 범위.
- `UNRECOVERED`: 사용자의 원문·정확한 칸·승인 여부를 회수하지 못한 부분.

## 프로젝트 권위 순서 및 범위

1. **사용자 명시적 수정·확정** > 기존 잠금 설계 > 구체적 채택 외부 소스 > 참고용 BNW 기본값.
2. 한국·중국·일본 원본을 회수하지 못한 셀은 `UNRECOVERED`. 임의로 충전·확정하지 않는다.
3. 문명/국가 정체성(`Civilization`), 왕조/체제, 식민정부, 점령지, 시대명을 서로 혼동하지 않는다.
4. 계보 화살표는 직계 승계, 정복, 지역적 역사 연계, 식민지 형성, 독립·분열, 혁명을 따로 분류할 필요가 있다.
5. 고도 도시국가/제국을 민족·대륙만으로 배제하지 않는다. 주요 문명 중심의 규모 원칙을 적용한다.
6. 지시 우선순위: 한·중·일 문명 → 다른 지역. 미주는 사용자가 보류함.
7. 현 단계 **지도자 배제**. 다만 문명 확정 후 동일 실존인물이 `Great Revolutionary → Leader`로 순차 전환 가능하다는 설계 방향은 보존한다(로스터 미확정).
8. 별도 12개 역사시대 계보와 게임 기술/사회제도의 **13시대(미래시대 추가)**는 구분한다.
9. 이번 감사는 **다른 시스템의 수치·파일을 수정하지 않는다**.
