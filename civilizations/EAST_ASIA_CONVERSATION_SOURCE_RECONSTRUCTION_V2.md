# 한·중·일 과거 대화 원안 회수 V2 — 서로 다른 출처와 시대틀 분리

2026-11-18 감사, 2026-11-18 같은 날 자료를 다시 확인해 정정. **독립 문명 최종 roster 아님.**

> **중대한 정정:** 2026-09-17 한국 **최초 AI 표**는 '고전'을 **3~6세기**, '후기 고대'를 **7~10세기**로 오배치했다. 따라서 최초 AI의 한국 시대별 내용을 **사용자가 수정한 12시대 연대 범위와 같은 열에 결합하면 안 된다**. 아래에서 두 표를 분리한다. 복원된 문구 역시 전체 원문 전사가 아닌 검색 가능한 대화 **요약 회수**이다. 사용자 작성의 완성된 한국 12시대 원본은 여전히 확보하지 못했다.

## A. 한국: 2026-09-17 05:57:43 UTC에 제시된 *AI 최초 표*의 회수 스냅샷 (미검증·사용자 승인 아님)

**시대명은 당시 AI 최초 표에 붙은 명칭이다. 각 명칭의 당시 연대 범위가 현재 고정된 12시대와 일치하지 않으므로, 현대의 12시대 시간 범위를 붙이지 않는다.**

| 당시 AI 시대명 | 당시 AI가 배치했던 내용 (요약 회수, 최종안 아님) |
|---|---|
| 고대 | 고조선 |
| 고전 | 삼국 |
| 후기 고대 | 삼국 말기·통일신라·발해·후삼국 |
| 중세 초기 | 고려 전·중기 |
| 중세 성기 | 고려 말·조선 전기 |
| 르네상스 | 조선 중기 |
| 탐험 | 조선 후기 |
| 계몽 | 조선 후기 |
| 산업 | 조선 후기·개항기 |
| 현대 | 대한제국·일제강점기 |
| 원자력 | 광복 이후 남북한·냉전·산업화 |
| 정보화 | 대한민국·조선민주주의인민공화국 |

- 당시 AI는 **고전=3~6세기, 후기 고대=7~10세기**로 잘못 표기했다. 사용자가 즉시 **“14~15는 르네상스로 해놨는데”**라고 지적했고, 이어진 정정에서 중세초기=7~10, 중세성기=11~13, 르네상스=14~15, 탐험=16~17, 계몽=18, 산업=19, 현대=20세기 초, 원자력=20세기 중후반, 정보화=21세기를 바로잡았다.
- **이 AI 한국표는 실재 역사연대 검증도, 사용자 최종 승인도 통과하지 않았으며 실제 게임용 셀로 재사용 금지.**
- 사용자께서 한국 역사 배치를 요청하면서 고조선·부여·고구려·백제·신라·발해·고려·조선·대한제국·대한민국·북한을 명시한 기록은 별도 있다. 이 원래 요청 목록을 AI가 만든 표와 혼동하지 않는다.
- 한국의 **교정 이후 최종 사용자가 승인한 12시대 셀**은 검색 가능한 근거에서 전체 복원되지 않았다.

## B. 중국·일본: 고정된 12시대 연대 기준으로 회수한 서로 다른 출처

| 후기 고대 (3~6세기) | 위진남북조·수 | 야마타이 → 야마토 (직접 계승 미확정) |

| 정보화 (21세기) | 중화인민공화국·중화민국 | 현대 일본 |

- **중국**: 원본 자료는 2026-09-25 07:17:37 UTC **사용자 메시지**의 국가·왕조 시대 계보. 이는 본래 사용자의 계보이고 'AI가 임의 구성한 문명 후보'가 아니다. 다만 **국가 계보가 완성된 플레이 가능 Civilization 슬롯의 잠금 여부는 별도 문제**다.
- **일본**: 위 행은 2026-09-26 08:04:45 UTC **AI 초안**, 사용자 원문에 야마타이·야마토를 다루라는 요청은 있었지만 AI 표 자체의 최종 승인 여부는 불명이다. 야마타이→야마토를 역사상 직접 국가 승계로 주장하지 않는다.
- 2026-09-17 일본 AI의 앞선 수정안에는 '고전 왜 소국 연맹 / 후기 고대 야마타이국·야마토 왕권 / 중세 초기 율령국가·헤이안 조정'이 있었다. 이 역시 최종 사용자 문명 로스터와 혼동 금지.
- 문화기(조몬)·시대명(전국/헤이안)·왕조/막부와 독립 국가의 **Civilization identity**는 아직 별도 판정이 필요하다. 현재는 역사 계보 대화 회수 기록이다.
