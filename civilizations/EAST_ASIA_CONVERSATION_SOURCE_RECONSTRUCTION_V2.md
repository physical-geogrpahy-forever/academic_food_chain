# 한·중·일 12시대 대화 원안 복원 V2 — 출처별 구분

기록일: 2026-11-18  
상태: **복구 중 / 최종 Civilization roster 미확정**

## 무엇이 달라졌는가

기존 V1은 한국 전체를 `미복원`으로 남겨두고 중국·일본을 GitHub 검토안으로만 다루었다. 이번 V2는 과거 대화 조회에서 **실제 회수한 2026년 9월 17일의 한국 AI 표, 9월 25일 사용자가 직접 제시한 중국 표, 9월 26일의 일본 AI 표**를 원안과 구분하여 한 표로 보존한다.

**이 문서의 핵심 주의:** 한국 열은 **당시 AI 초안이지 사용자가 승인한 최종 원본이 아님**. 원래 한국 AI 초안에는 삼국·통일신라가 후기고대(3~6세기), 고려 말·조선 전기가 중세성기(11~13세기) 등에 잘못 배치된 연대 오류가 있다. 이 오류를 임의로 '교정'하여 원래 말과 다르게 바꾸지 않고, **당시 AI가 제시했던 내용으로만 기록**한다. 일본도 당시 AI 제안이며 사용자가 국가 단위/직계 계승 추측을 지적한 뒤의 검토안이므로 최종 잠금이 아니다.

- 일본의 `야마타이 → 야마토`는 당시 AI 표기 형태다. **직접 국가 승계를 입증한 화살표로 해석하지 말 것**. 야마타이국과 야마토 왕권의 직접 계승은 역사적으로 불확실하다는 사용자의 지적이 별도로 보존되어 있다.
- 한국은 9월 17일 사용자 요청에 고조선·부여·고구려·백제·신라·발해·고려·조선·대한제국·대한민국·북한이 언급되었으나, 위의 **AI 초안은 이 요청을 정확히 시대별로 배치하지 못했다**. 사용자 승인 이후의 수정표는 현 조회에서 회수하지 못했다.

## 기존 V1에서 실제 수정해야 하는 평가

- **중국:** V1의 `GITHUB_HANDOFF_REVIEW_NOT_LOCKED`만으로 출처를 표시한 것은 불충분하다. 사용자 **직접 계보 원안**이 2026-09-25에 존재했다. 그러나 사용자 계보 원안이 곧 모든 세부 Civilization identity의 확정은 아니다.
- **한국:** V1의 `미복원`은 **사용자가 승인한 최종 각 셀의 관점에서만** 맞고, 당시 AI가 제시한 최초 표까지 없다는 뜻으로 읽으면 틀린다. 현재 회수된 한국 AI 최초 표에는 연대상 오류가 있어서 확정 데이터로 사용 금지.
- **일본:** 9월 17일의 국가 단위 교정과 9월 26일 AI 제안을 모두 남긴다. AI의 `야마타이 → 야마토` 표기를 역사적 직접 승계로 확정하지 않는다.

## 게임 내용 반영 원칙

이 문서는 **과거 기록 회수 문서**이며 새로운 문명 목록·지도자·능력·후계 국가를 만들지 않았다. 실제 게임용 국가 문명 로스터는 사용자가 이미 확정한 원문을 확보한 항목만 잠금한다. 현재 사용자 지시대로 **문명만** 다루고, 북미·중앙아메리카·카리브는 보류한다.
