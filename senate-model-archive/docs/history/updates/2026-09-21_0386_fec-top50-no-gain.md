# FEC June-30 fundraising direction decision

## 날짜
2026-09-21

## 결과

OpenFEC API rate limit을 피하기 위해 FEC 공식 18-month Top 50 Senate campaign tables를 사용했다.

사용 지표:
- receipts
- contributions from individuals
- cash on hand

D/R 양 후보가 같은 지표의 Top 50에 모두 포함된 경우에만 race-level finance share를 계산했고, 미포함 후보를 0으로 처리하지 않았다.

Coverage:
- 전체 99개 중 36개
- 2014: 14개
- 2018: 12개
- 2022: 10개

방향 적중:
- baseline: 94/99 = 94.9%
- finance adjusted: 94/99 = 94.9%

2018과 2022 training-only 선택은 모두 gamma=0을 선택했다.

## 판정

조기 모금력은 현재 99-race historical OOS에서 fixed-poll baseline보다 winner-direction accuracy를 높이지 못했다.

따라서 현재 모델에는 추가하지 않는다.

Primary benchmark는 94/99 = 94.9%를 유지한다.
