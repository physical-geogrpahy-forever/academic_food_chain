# Candidate-level FEC Form 3 run fix

## 날짜
2026-09-21

후보 master와 OpenFEC Form 3 API 조회는 정상 작동했고 Form 3 누적 재정 필드도 확인되었다. 그러나 첫 후보별 실행은 finance coverage가 0이었다.

원인은 API 요청에 `most_recent=true`만 사용하여 각 committee의 Q2 보고서가 아니라 다른 report period가 선택될 수 있었고, workflow는 이미 폐기한 옛 MD 파일명을 `git add`하고 있었다.

수정:

- OpenFEC `/reports/house-senate/` 요청에 `report_type=Q2`를 명시한다.
- `coverage_end_date`는 ISO `YYYY-MM-DD`와 `MM/DD/YYYY` 표현을 모두 인식한다.
- workflow 저장 대상 MD를 실제 candidate-level Form 3 결과 문서명으로 수정한다.

첫 실행의 0 coverage는 성능 결과로 간주하지 않는다. 수정된 동일 실험을 재실행한다.
