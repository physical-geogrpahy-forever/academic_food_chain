# Giant Death Robot Optional Endgame Module V1

Date: 2026-09-21
Status: **OPTIONAL, NOT BASELINE**

The baseline project does not include the Civilization VI Giant Death Robot as a normal Atomic/Information-era unit.

Reason:
- its presence distorts the otherwise historical generic military progression;
- several Future technologies become GDR-upgrade containers in Civ6, while this project uses them for broader civilian/scientific systems;
- users may still want a high-fantasy/future-war option.

## Optional module

If enabled:
- Robotics -> Giant Death Robot
- Advanced AI -> Drone Air Defense upgrade
- Advanced Power Cells -> Particle Beam Siege Cannon upgrade
- Cybernetics -> Enhanced Mobility upgrade
- Smart Materials -> Reinforced Armor upgrade

These do not replace the general-purpose effects of those technologies.

## Baseline behavior

If the module is disabled:
- no Giant Death Robot unit exists;
- the five source unlocks do not appear;
- Robotics, Advanced AI, Advanced Power Cells, Cybernetics and Smart Materials retain their ordinary industrial, information, energy and materials roles.
