# Ancient Policy Effects V1

Date: 2026-09-21
Status: **LOCKED**

The Ancient policy layer uses Civilization VI Gathering Storm values as the main numeric baseline, translated only where the project's Civ V-style structure requires it.

## Directly retained
- Discipline: +5 Combat Strength against Barbarians
- Survey: Recon experience x2
- God King: Capital +1 Faith, +1 Gold
- Urban Planning: every city +1 Production
- Agoge: +50% Production toward Ancient/Classical melee, ranged, anti-cavalry
- Caravansaries: every Trade Route +2 Gold
- Maritime Industries: +100% Production toward Ancient/Classical naval units
- Maneuver: +50% Production toward Ancient/Classical cavalry
- Strategos: +2 Great General Points/turn
- Conscription: maintenance -1 Gold/unit/turn
- Corvée: +15% Production toward Ancient/Classical Wonders
- Colonization: +50% Settler Production
- Land Surveyors: tile purchase cost -20%
- Inspiration: +2 Great Scientist Points/turn
- Revelation: +2 Great Prophet Points/turn

## Structural adaptations

### Ilkum
Civ6 Builder production becomes:
**+30% Production toward Workers**

### Limitanei
The project does not import Civ6 Loyalty as a full baseline system.

Therefore Civ6's garrison Loyalty effect becomes:
**garrisoned cities suffer 25% less occupation/unrest pressure.**

This keeps the frontier-garrison function without introducing a second city-stability framework.
