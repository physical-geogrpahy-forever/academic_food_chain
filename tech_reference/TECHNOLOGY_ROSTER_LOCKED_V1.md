## Source precedence

The project technology roster is built in this order:

1. **Civilization VI: Gathering Storm** — base skeleton
2. **Civilization V: Brave New World** — add technologies absent from Civ VI
3. **Pouakai's Civilization V Enlightenment Era** — add technical nodes that fill the 16th-19th century gap
4. avoid creating original technology names unless later implementation exposes a real missing mechanic

If a Civ V or mod technology duplicates a locked civic or a Civ VI technology, the Civ VI / civic implementation wins.

## Why the roster is larger than either base game

Civilization VI: Gathering Storm provides 77 technology nodes including the Future Era.
The merge adds:
- 21 non-duplicating Civilization V technologies
- 5 technical technologies from Enlightenment Era

77 + 21 + 5 = **103**.

## Major chronology corrections to Civilization VI

The project does not preserve Civ VI's era labels when they are clearly inconsistent with the project's finer chronology.

Examples:
- **Chemistry** moves from Civ VI Modern to project Enlightenment (18C).
- **Mass Production** moves from Civ VI Renaissance to project Industrial (19C).
- **Replaceable Parts, Steel, Refining, Electricity** move from Civ VI Modern to project Industrial.
- **Advanced Flight, Rocketry, Advanced Ballistics, Combined Arms, Plastics** move from Civ VI Atomic to project Modern (early 20C).
- **Telecommunications, Satellites, Guidance Systems, Lasers, Composites, Stealth Technology, Robotics, Nuclear Fusion** move from Civ VI Information to project Atomic (mid-late 20C).
- Civ VI Future technologies are folded into the project's Information era because the project has no separate Future era.

These are era reassignments only. Exact prerequisites will be redesigned in the next phase.

## Important naming notes

- **Manufacturing** and **Mass Production** are both retained:
  - Manufacturing = 18C manufactory / organized production transition
  - Mass Production = 19C mechanized standardized production
- **Navigation** and **Cartography** are both retained:
  - Navigation = practical oceanic navigation
  - Cartography = systematic mapping
- **Fortification** is a technology while **Defensive Tactics** is a civic:
  - Fortification = material/engineering knowledge
  - Defensive Tactics = military doctrine/institution
- **Atomic Theory** precedes **Nuclear Fission** conceptually.
- **Ecology** is a technology/scientific field while **Environmentalism** is a civic/social movement.
- **Telecommunications** is placed in the Atomic era because the underlying technology is 20C; Social Media remains a 21C civic and can use Telecommunications as a hard gate.
