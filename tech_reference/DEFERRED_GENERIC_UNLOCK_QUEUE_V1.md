## Source rule for resolving a deferred generic item

**Civ V first -> historical/functional reconciliation -> Civ VI fallback -> minimal historical invention**

A deferred item is not automatically a content gap. If Civ VI content is already represented elsewhere under a more appropriate technology/civic, do not duplicate it merely to fill a node.
