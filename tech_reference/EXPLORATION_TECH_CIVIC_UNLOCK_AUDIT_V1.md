## Cartography, Astronomy and Navigation

Civilization VI puts Caravel and ocean movement at Cartography.

Civilization V puts:
- Caravel;
- Observatory;
- ocean crossing;
at Astronomy.

The project gives Civ V first priority when source placements conflict unless functional/historical fit clearly argues otherwise.

Final:
- **Cartography -> Cartographic Surveying**
- **Astronomy + Exploration -> Caravel**
- **Astronomy + Exploration -> Ocean Crossing**
- **Astronomy -> Observatory**
- **Navigation -> Seaport + advanced naval navigation**

This prevents Cartography, Astronomy and Navigation from all becoming duplicate ocean-navigation technologies.

## Square Rigging and Warships

Civilization VI:
- Square Rigging -> Frigate
- Square Rigging -> +1 embarked movement

Pouakai Enlightenment Era:
- Warships -> Frigate

Because the project deliberately retained **Warships** from the adopted Enlightenment Era mod:

Final:
- **Square Rigging -> +1 embarked movement + advanced sailing rigging**
- **Warships -> Frigate**

This gives the otherwise redundant Warships node a clean naval-combat role without inventing a new unit.

## Navigation

Civilization V Navigation unlocks Frigate and Seaport.

Pouakai Enlightenment Era also makes Ship of the Line a standard unit at Navigation.

Final:
- Frigate moves to Warships;
- **Navigation -> Seaport**
- **Navigation -> Ship of the Line**
- **Cartography + Exploration -> Navigation School**

Navigation School adapts the Civ5 Exploration policy concept into a one-per-civilization maritime academy rather than adding another policy with the same name.

## Acoustics

Civilization V Acoustics unlocks Opera House and Musicians' Guild.

Because these are institutions rather than pure physical discoveries:

Final:
- **Acoustics + Patronage -> Opera House**
- **Acoustics + Patronage -> Musicians' Guild**
- Great Musician generation occurs through Musicians' Guild.

No Great Person tile improvement is added.

The existing corporation map is imported unchanged:
**Acoustics + Capitalism -> Cultural Manufactured Goods corporation sector.**

## Flintlock

Pouakai Enlightenment Era directly supplies:
- Line Infantry
- Skirmisher
- Gunsmith

These fit the project's firearm chronology.

Final firearm line so far:
- Gunpowder -> Fire Lance
- Metallurgy -> Arquebusier
- **Flintlock -> Line Infantry**
- later Rifling -> rifle infantry

Skirmisher remains the ranged upgrade candidate from Crossbowman.

Gunsmith provides gunpowder-unit production support, with the exact percentage deferred.

## Warships

Pouakai Enlightenment Era:
**Warships -> Frigate**

Retained directly.

This separates:
- navigation technology;
- merchant/ocean systems;
- purpose-built naval combat vessels.

## Fortification

Pouakai Enlightenment Era:
- Field Gun
- Bastion

The project already has:
- Fort at Engineering;
- Bastion Fort/Renaissance Walls at Siege Tactics.

Therefore Fortification does not duplicate the same defenses.

Final:
- **Fortification -> Field Gun**
- **Fortification -> Star Fort / Advanced Bastion upgrade**
- existing Fort/Bastion Fort receives an advanced gunpowder-fortification upgrade.

Great General Citadel remains removed.

## Exploration civic

Civilization VI Exploration unlocks Merchant Republic and colonial/naval policies.
Civilization V Exploration provides maritime infrastructure, Navigation School, merchant-navy and treasure-fleet concepts.
Pouakai Enlightenment Era's Exploration technology adds Explorer and Galleon.

Final:
- **Exploration -> Merchant Republic**
- **Cartography + Exploration -> Navigation School**
- **Cartography + Exploration -> Explorer**
- **Astronomy + Exploration -> Galleon**
- retain a naval exploration movement/sight concept.

Merchant Navy and Treasure Fleets move to Mercantilism because their economic logic is more specifically mercantilist.

Colonial Offices moves to Colonialism.

## Reformed Church

Civilization VI Reformed Church directly unlocks Theocracy and:
- Wars of Religion
- Religious Orders
- Simultaneum

All are retained.

Simultaneum must be translated from Holy Site district conditions into Temple/religious-building conditions.

## Mercantilism

Civilization VI Mercantilism supplies Privateer, Logistics and Triangular Trade.

Final:
- **Warships + Mercantilism -> Privateer**
- Logistics
- Triangular Trade
- **Navigation + Mercantilism -> Merchant Navy**
- **Navigation + Mercantilism -> Treasure Fleets**

The Civ6 Camp Food/Production bonus is dropped as functionally weak.

## Colonialism

Civilization VI places Colonialism after Mercantilism and uses Astronomy as its Inspiration.

Final cross-tree gate:
**Astronomy + Colonialism -> Overseas Colonial Administration**

Retained policy candidates:
- Colonial Offices
- Colonial Taxes
- Raj
- Native Conquest

These represent historical colonial administrative/extractive systems and are treated as optional policies rather than universal benefits.

Civ6 +2 Envoys is retained.

The Fishing Boats production bonus is dropped because it has little direct relationship to colonial institutions.

## Scientific Revolution

The project civic draws directly from Civilization V Rationalism's Scientific Revolution policy.

Retained concept:
**Education + Scientific Revolution -> stronger Research Agreement science**

The original Civ5 +50% coefficient is not locked yet.

Additional cross-tree concept:
**Astronomy + Scientific Revolution -> Observational Scientific Method**

This does not replace the next-era **Scientific Theory** technology.

The older free-technology reward is dropped in favor of sustained science systems.

## Sovereignty

The project uses Sovereignty as a state-institution civic, not Civ5 Rationalism's science-economy policy.

Final:
- formal territorial/state sovereignty;
- centralized charter and taxation authority;
- institutional prerequisite for later Mercantilism.

Pouakai Enlightenment Era's Manor is not made a universal building because it is too regionally specific.

Pouakai's Sovereignty-based World Congress founding trigger is also not duplicated. The project already places World Congress behind:
**Printing + Diplomatic Service**.
